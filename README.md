# AnyaPasswordGraph

Веб-сайт на FastAPI: вводишь пароль — получаешь 10 метрик, 3 сценария взлома,
вердикт «Ани» и радар на canvas.

**Без внешних API. Без БД. Без списков паролей. Только формулы.**
Сделал Клим, 13 лет.

---

## 📦 Стек
- Python 3.11
- FastAPI + Uvicorn + Jinja2
- Всё остальное — стандартная библиотека (`math`, `difflib`, `collections`)

---

## 🚀 Локальный запуск

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload
```

Открой: <http://127.0.0.1:8000>

---

## ☁️ Деплой на Render (free tier)

1. Залей проект на GitHub.
2. На Render: **New → Web Service** → подключи репозиторий.
3. Настройки:
   - **Environment:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `uvicorn main:app --host 0.0.0.0 --port $PORT`
   - **Instance Type:** Free (512 МБ ОЗУ)

> ⚠️ На free tier сервис **засыпает через 15 минут** без запросов.
> Первый запрос после сна — **холодный старт ~30 секунд**. Это нормально.

## 🧮 10 формул

| # | Формула | Что считает |
|---|---------|-------------|
| 1 | Энтропия Шеннона `H = -Σ p·log2 p` | хаотичность символов |
| 2 | Комбинации `C = N^L` | сколько всего вариантов |
| 3 | Время `T = C / (2·R)` | сколько лет ломать |
| 4 | Индекс совпадений `IC = Σnᵢ(nᵢ-1)/N(N-1)` | повторяющиеся символы |
| 5 | Жаккар биграмм `J = |A∩B|/|A∪B|` | паттерны типа `abcabc` |
| 6 | Левенштейн до слабых слов | близость к `qwerty`, `password`... |
| 7 | CV чанков `σ/μ` | рваность структуры |
| 8 | TTR `U/T` | разнообразие символов |
| 9 | Доля спецсимволов и цифр | насыщенность |
| 10 | Нормированная энтропия `H/log2(N)` | предсказуемость |
